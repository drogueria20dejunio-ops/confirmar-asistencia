# Check-in Evento - Tomamos IMPULSO juntos

Aplicación web simple para validar asistencia al evento.

## Archivos
- `index.html`: aplicación completa.

## Cómo subir a GitHub Pages

1. Crear un repositorio nuevo en GitHub.
2. Subir el archivo `index.html` a la raíz del repositorio.
3. Ir a `Settings`.
4. Ir a `Pages`.
5. En `Build and deployment`, elegir:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
6. Guardar.
7. GitHub generará una URL pública del estilo:
   `https://TU-USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/`

## Uso
- Campo 1: DNI
- Campo 2: Número de farmacia
- Botón: Confirmar asistencia

La validación real se hace por DNI. El número de farmacia se guarda si se ingresa.
